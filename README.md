## 🧠 Como penso software

Alguns princípios que procuro aplicar nos meus projetos:

- regras críticas de negócio devem permanecer no backend
- autenticação e autorização são responsabilidades diferentes
- APIs precisam de contratos claros
- dados devem ser validados antes do processamento
- testes reduzem regressões e dão segurança para evoluir
- documentação facilita manutenção e onboarding
- decisões técnicas devem considerar também o problema de negócio
